Runtime operational settings. These override the environment defaults and take effect immediately.

Break-glass access

How long a session granted by scanning a break-glass card lasts (maximum 12 hours). These sessions are never renewed. Revoking or re-minting the card ends them early. Keep it short.

Use notifications

Comma-separated. Emailed whenever a break-glass code is used. Leave blank to disable email notifications.

Site logo
